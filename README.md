# 🎧 Spotify Music Analytics Dashboard

An interactive Tableau dashboard exploring Spotify track popularity, genres, danceability, duration, and explicit content.

## 🔗 Interactive Dashboard

[View the dashboard on Tableau Public](https://public.tableau.com/views/Spotify_Music_Analytics_pro/SpotifyMusicAnalytics)

## 📊 Dashboard Highlights

- Average popularity and track duration
- Number of unique tracks and genres
- Top genres by average popularity and danceability
- Explicit and non-explicit content distribution
- Popularity and track duration distributions
- Top 10 tracks by popularity

## 📁 Dataset Overview

- **Total records:** 114,000
- **Unique tracks:** 89,741 distinct track IDs
- **Genres:** 114

A track may appear in more than one record. Record-based counts and averages therefore reflect the records in the dataset, rather than only distinct tracks.

## 🛠️ Tool Used

- Tableau

## 📌 Notes

- The track duration distribution displays records up to 10 minutes.
- Popularity scores and other metrics describe this dataset and should be interpreted within its scope.
